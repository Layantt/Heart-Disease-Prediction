
# Heart Disease Prediction – Feature Selection

## Overview
A code sample from a Data Mining team project focused on analyzing patient health data to predict heart disease.

## Code Sample
Comparison of three feature selection techniques:
- **SelectKBest:** ANOVA F-test
- **RFE:** Recursive Feature Elimination
- **L1 Regularization:** Lasso
